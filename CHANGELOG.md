# Changelog

Sve značajnije promjene po sedmicama (odgovara `Wk{n}:` commit uzorku).

## 0.2.0 — Wk1c

- Report page is now deep-linkable (`/?repo=owner/name` updates the URL bar)
- Recent searches: last 5 saved in localStorage, one click to re-run
- "Try:" chips with a few example repos when the page is empty
- `/` keyboard shortcut focuses the input box
- Rotating fun loading messages (":knocking on github's door…" etc.)
- "Copy report link" button on the report card
- Package renamed from the create-next-app default (`app-scaffold`) to `git-pulse`

## 0.1.0 — Wk1b

- Momentum score (0–100) with plain-English labels
- Contributor count (via the Link pagination header) and issues-per-contributor
- Commit activity chart, color-coded language bar, stat tiles
- Custom dark theme with amber accent
